# Release {{ release }}

Die Dateien zum [Download]({{DLLINK("release/"+release)}}).

## Zusammenfassung {: #summary}

Eine komplett neue Struktur der Bedienung und der Seiten innerhalb von AvNav.
Die wichtigsten Änderungen:
  
  * Ein [Hauptmenü](../../special/mainmenu.md) zum schnellen navigieren zwischen den Seiten
  * Start mit der Kartenseite
  * Zusammenfassung der Anzeigen und Dialoge nach Funktionsbereichen
  * Neue Icons
  * Wesentlich mehr Erweiterungs-Möglichkeiten per [CSS](../../special/usercss.md) und [Java Script](../../special/userjs.md). Umstieg auf JavaScript Module mit automatischem Reload.
  * [Plugins](../../special/plugins-extensions.md) die als zip Datei zur Laufzeit installierbar sind (auch für Android)
  * [Eigene Kartentypen](../../special/charts.md#owntypes)
  * Vektorkarten mit MapLibre
  * Komplett neue [Dokumentation](../../index.md) (auch als Plugin installierbar) inklusive [Videos](../../allvideos.md) zur Erklärung der Grundfunktionen
  * Nutzung von NetworkManager für die [IP Konfiguration](../../special/connecting-pi.md) auf Raspberry Pi (Debian Trixie)
  * veränderte Pakete avnav-raspi-base und avnav-raspi-network statt avnav-raspi
  * Android: Anpassungen an Android 16 (API 36)

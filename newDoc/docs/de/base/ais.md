# AIS

Auf der [Navigationsseite](navpage.md) werden neben der Karte, den Anzeigen (Widgets) und den Navgations-Informationen auch AIS Objekte und zugehörige Informationen angezeigt. Das erfordert natürlich, das AvNav entsprechende [NMEA0183 Datensätze](../special/nmeadata.md) (AIVDO,AIVDM) oder AIS Daten von [SignalK](../special/signalk.md) empfängt.
Neben der Darstellung auf der Karte erfolgt auch eine Berechnung der voruassichtlichen Positionen mit minimaler Entfernung.


## Details
Für Darstellungs- und Berechnungsdetails siehe die [ausführliche Information](../special/ais.md).

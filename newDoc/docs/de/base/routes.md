# Routen
Beschäftigen wir uns nun mit der Routen-Funktion.  

Das Erstellen einer Route geht am einfachsten direkt aus dem Navigations-Fenster über die Schaltfläche für die Route. Wenn man sie anklickt, landet man im Routen Editor. Die Kartenansicht bleibt, aber die Buttonleiste rechts hat sich verändert. Wie eine Route angelegt wird und wo Wegepunkte einzugeben sind und so weiter, wird nun gezeigt. Schritt eins: Man klickt links unten in das Routen Widget und legt eine neue Route an, indem man der Route einen neuen Namen mit Klick auf New gibt. Wir wählen hier den Namen „Test“ und bestätigen mit okay.  Nun zeigt der Dialog den neuen Namen. Ein zweiter Klick auf OK führt dazu, dass auch 
im Widget die Route „Test“ existiert, aber es gibt natürlich noch keinerlei Wegepunkte

Schritt zwei ist das Setzen von Wegepunkten, das erfolgt in AvNav, indem das Fadenkreuz auf den Punkt gesetzt wird, wo ein Wegepunkt entstehen soll. Wir wählen hier die Tonne westlich von Drejö, besser etwas daneben aus erfindlichen Gründen, und klicken auf den Button „After“.  

Nun soll ein zweiter Wegepunkt angelegt werden. Er soll uns in die Durchfahrt zwischen Drejö und Avernakö führen. Dorthin muss also das Fadenkreuz, dann drücken wir wieder auf After. Sollten wir jetzt vergessen haben, dass wir zwischen Wegepunkt Eins und zwei noch einen dritten Wegepunkt legen wollen, kann man nun einen dritten Wegepunkt zwischen die beiden legen, indem man auf Before klickt. D.h. jetzt wird Wegepunkt Nummer drei vor den aktuell aktiven Wegepunkt zwei gelegt.  Das sieht dann so aus. Das hat gut geklappt. 

Die Arbeit mit dem Fadenkreuz mag im ersten Augenblick etwas umständlich wirken im Vergleich zu direkten Klicks auf den Touchscreen. In Situationen mit einem sich stark bewegenden Schiff auf einem kleineren Bildschirm und klammen Fingern wird man diese Art der Bedienung aber zu schätzen lernen.  

Jetzt geht’s darum, weitere Routing-Funktion kennen zu lernen, zum Beispiel das Verlegen eines bestehenden Wegepunktes. Zum Beispiel soll Wegepunkt 1 dann doch auf die Ansteuerung von Aeroesköbing gelegt werden. Dazu muss Wegepunkt 1 zunächst markiert werden. Das geht so, indem du einfach in der Karte direkt auf den Wegepunkt klickst. 

Wem das zu hakelig oder zu eng ist, kann auch in Widget den Wegepunkt auswählen.  Wenn Wegepunkt 1 ausgewählt ist, muss das Fadenkreuz auf die neue Koordinate gesetzt werden, mit einem Klick auf die Schaltfäche „Shift“ verschiebt sich Wegepunkt 1 nun dorthin.  

Soll ein Wegepunkt aus der Route gelöscht werden, nutzt du dafür die Schaltfläche delete. Natürlich musst du vorher den Wegepunkt, den du löschen möchtest, markieren - so wie eben gezeigt.  

Das sind im Prinzip die Dinge, die man braucht, um eine Route aufzubauen.  

Man kann jetzt noch weitere Möglichkeiten nutzen, indem man die Schaltfläche Tools anklickt und hier show Wp buttons. Jetzt kann man hier noch mal mit den Schaltflächen Next und Previous von Wegepunkt 
zu Wegepunkt klicken, wenn die Arbeit im Widget oder in der Karte als ungünstiger empfunden wird.  
Über Edit kann jeder einzelne Wegepunkt editiert werden, um zum Beispiel einen neuen Namen zu vergeben. Mit Locate kannst du den angewählten Wegepunkt schnell wieder ins Kartenfenster holen, wenn die Karte aus irgendwelchen Gründen woanders hin verschoben wurde. Das kannst du allerdings auch erreichen, wenn du den Wegepunkt im Widget anklickst. 

Es gibt immer wieder mindestens eine zweite Option, das ist gut so.  
Nun sind alle Eingaben gemacht, es folgt Schritt 3, die Route soll aktiviert werden. Das geht über den Klick auf den Start-Button. Bevor das passiert, sollte noch einmal geprüft werden, welcher Wegepunkt aktuell aktiv ist, denn dorthin würde die Route starten. Wir legen also Wegepunkt 1 als erstes Leg von unserer Position aus fest und klicken auf Start.  

Die Route wird nun aktiv, die Ansicht springt zurück in das normale Navigationsfenster. Aus 
dem Start-Button wird ein Stop-Button. Mit ihm könnte ich die Aktivierung der Route wieder zurücknehmen. Dass deine Route nun aktiv ist, siehst du außerdem daran, dass die Widgets 
die routenbezogenen Werte anzeigen, also die Distanz zum nächsten Wegepunkt, den Kurs dorthin, 
im RTE-Widget die Länge der Route und die ETA. Über die Tools können interessante Funktionen 
während des Abfahrens der Route aktiviert werden. Sollte man sich entscheiden, einen Wegepunkt auszulassen, ohne die Route gleich in ihrem Ablauf ändern zu wollen, ist der Skip-Button die richtige Wahl: Den auszulassenden Wegepunkt auswählen, dann auf Skip klicken, schon springt die Route auf den nächsten Wegepunkt. Das kann hilfreich sein, wenn man einen Wegepunkt in einer so großen Entfernung passiert hat, dass das Erreichen des Wegepunktes nicht quittiert wird. Natürlich kann die Route ,während sie läuft, auch verändert werden, indem man wieder in den Routen-Editor wechselt, 
um zum Beispiel einen Wegepunkt doch wieder zu verlegen. Wegepunkt 2 soll beispielsweise näher an die Tonne rücken. Das läuft wie bereits erläutert über den Button Shift.  Die Änderung wird direkt übernommen, während die Route läuft. Das Speichern der Route, wenn sie angelegt oder verändert wurde, läuft im Hintergrund automatisch. Wenn du nach einer Änderung der Route auch eine XTE-Aktualisierung erreichen möchtest, klicke auf Restart. Um einen Überblick zu bekommen, wo sich die Dateien zu den Routen befinden, muss man über das Menü zum Bereich Routen wechseln. Dort werden alle gespeicherten Routen gelistet, man sieht, dass die Route Test vor kurzer Zeit automatisch gespeichert worden ist. Nun kann sie noch kopiert, heruntergeladen oder editiert werden und sie kann als Overlay in eine Karte gelegt werden.  Das sind Dinge, die du in Ruhe für dich ausprobieren kannst. 
Was im Routenbereich noch möglich ist, erklärt sich eigentlich direkt aus den Schaltflächen.  
Zum Ende soll eine Schaltfläche noch einmal herausgehoben werden, nämlich connect.    
Im Normalzustand ist "connect" in der Regel aktiv. Dann werden die Routen-Operationen auf dem Server 
ausgeführt und alle angeschlossenen Displays zeigen die gleichen Werte.  
Wenn “connect” deaktiviert wird, kann man auf einem lokalen Display andere Routen 
ausprobieren und ändern - der Server arbeitet weiter mit der alten Route. Diese Routen werden 
nur auf dem lokalen Display verarbeitet.  

Wenn ich mit einem zweiten Display auf einem zweiten Gerät arbeite, sollte immer die Schaltfläche connect aktiv sein, damit Server und Client, also das zweite Gerät, datentechnisch miteinander verbunden sind. Sonst bleibt das Speichern einer Route auf den lokalen Rechner beschränkt. Was das im Einzelnen bedeutet, kann man noch einmal in der Doku nachlesen. Das war’s zur Erstellung von Routen.

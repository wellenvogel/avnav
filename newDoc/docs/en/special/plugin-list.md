# List of AvNav plugins

AvNav plugins are managed in an [online catalog](https://wellenvogel.github.io/avnav-plugin-catalog/en/list.html).<!--@@linkchanged--> Through this catalog, their descriptions and the respective authors can be reached.


## Documentation as a plugin {: #documentation}

This documentation can be installed in AvNav as a plugin. With every [release](../installation/release.md) a file named documentation-xxx.zip is provided. To install it, download this file from the corresponding [release directory]({{DLLINK("release")}}) and upload it to AvNav on the plugin page

{{MM("MMpluginspage")}}

using the {{BT("Upload")}} button. The documentation creates a button ![Manual](../../img/manual.svg){.inline-image} on the user app page

{{MM("MMaddonpage")}}

. This button can be used to open the documentation.

The videos are not embedded directly in the plugin, but are opened as external links on YouTube.

If you want to have the videos available offline as well, you can additionally install the AvNav documentation videos plugin. It can be downloaded from a [fixed link]({{DLLINK("supplement/docvideos.zip")}}) because it changes only very rarely.

After installing these videos, there is an additional button ![Video Documentation](../../img/video-help.svg){.inline-image} - if you open the documentation via this button, the videos are embedded and can also be used offline.

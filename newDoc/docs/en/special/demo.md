Demo
====

The [demo]({{HPLINK("viewern/avnav_viewer.html?navurl=../viewer/avnav_navi.php&readOnlyServer=true")}}) provides a brief insight into the program functions of AvNav.  
The "connected" mode - i.e., the transmission of the routing destination from one browser to another - does not work here.

The charts are sourced (live) from the BSH <https://www.geoseaportal.de> and from [http://www.openseamap.org/](http://www.openseamap.org) (see their copyright).  
The data from the BSH comes very slowly - this causes the chart rendering to take some time. If you wish to use these charts, you can also download them with the [MobileAtlasCreator](https://mobac.sourceforge.io/) - see [Charts](../base/charts.md).  
The GPS data is from a trip in the summer of 2013 - Klintholm->Vitte. This allows you to see some of the program features (including the AIS display).   
The time is somewhat "compressed" - i.e., the GPS time runs at about double speed. When the demo reaches the "end," there is a jump back to near Klintholm - the track will look a bit strange there. In such a case, simply close the demo window and restart it.

To start, it makes sense to click on the boat button and then zoom in a little...  
Then continue playing.  
The upload and download functions may potentially not work correctly in all browsers in demo mode. However, they should be testable with Firefox and Chrome.

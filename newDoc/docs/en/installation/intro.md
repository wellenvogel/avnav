# General

AvNav is available for various platforms and operating systems.

| Platform/Operating System | Notes |
| --- | --- |
| [Raspberry Pi/Linux](raspberry.md) | There are ready-made images for operation with or without a screen, or you can install packages on a system. Installation under OpenPlotter is also possible. |
| [Linux](linux.md) | There are ready-made Debian and RPM packages for installation on various Linux systems. |
| [Android](android.md) | For Android, AvNav is available as an app in the store or for download. |
| [Windows](windows.md) | AvNav can also run on Windows. There is an installer and downloads for the software. |

## Versions

AvNav is delivered as a ready-made Raspberry Pi image, as a package, as an installable zip file, or as an APK for Android. At intervals, new "released" versions are provided. Between releases, developer versions (beta) are made available. These serve for the timely testing of new functions - but may still contain errors.

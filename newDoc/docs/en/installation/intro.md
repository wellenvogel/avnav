# General

AvNav is available for various platforms and operating systems.

| Platform/Operating System | Notes |
| --- | --- |
| [Raspberry Pi/Linux](raspberry.md) | Ready-to-use images are available for operation with or without a screen, or packages can be installed on an existing system. Installation under OpenPlotter is also possible. |
| [Linux](linux.md) | Ready-to-use Debian and RPM packages are available for installation on various Linux systems. |
| [Android](android.md) | For Android, AvNav is available as an app in the store or for download. |
| [Windows](windows.md) | AvNav can also run on Windows. An installer and downloads for the software are available for this purpose. |

## Versions

AvNav is delivered as a ready-made Raspberry Pi image, as a package, as an installable zip file, or as an APK for Android. At intervals, new "released" versions (releases) are provided. Between releases, developer versions (beta) are made available. These serve to test new features early on - but may still contain errors.

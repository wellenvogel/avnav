# Release {{ release }}

The files for [download]({{DLLINK("release/"+release)}}).

## Summary {: #summary}

A completely new structure for the operation and pages within AvNav.
The most important changes:
  
  * A [main menu](../../special/mainmenu.md) for quick navigation between pages
  * Starts with the chart page
  * Grouping of displays and dialogs by functional areas
  * New icons
  * Significantly more extension options via [CSS](../../special/usercss.md) and [Java Script](../../special/userjs.md). Switch to JavaScript modules with automatic reload.
  * [Plugins](../../special/plugins-extensions.md) that can be installed as a zip file at runtime (also for Android)
  * [Custom chart types](../../special/charts.md#owntypes)
  * Vector charts with MapLibre
  * Completely new [documentation](../../index.md) (can also be installed as a plugin) including [videos](../../allvideos.md) explaining the basic functions
  * Use of NetworkManager for [IP configuration](../../special/connecting-pi.md) on Raspberry Pi (Debian Trixie)
  * Changed packages avnav-raspi-base and avnav-raspi-network instead of avnav-raspi
  * Android: Adjustments for Android 16 (API 36)

## AvNav Developer Versions (Beta)

To provide updates for broad testing between release versions, beta versions are available. These may not be fully tested, so you should expect potential errors.

[Click here]({{DLLINK("daily")}}) to access the beta versions.

How to install these beta versions depends on the system.

### Linux/Raspberry

You can download the packages directly and install them as described under [Package installation Raspberry](raspberry.md#packages) or [Package installation Linux](linux.md#packages).

If you are using an [AvNav Image](raspberry.md#images), you can also set up the repository for beta versions there. TODO

## Android

For Android, you can download and install the APK file directly. The application is then named "AvNav-beta" and can be used alongside a standard AvNav installation.

## Windows

On Windows, the update function of the [installer](windows.md) can be used. There, the URL of one of the zip files from the list of betas is entered under "Update".

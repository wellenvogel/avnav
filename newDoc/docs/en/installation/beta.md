## Avnav developer versions (beta)

To provide updates for broad testing between release versions, there are beta versions available. These may not be fully tested, so you should expect potential errors.

[Click here]({{DLLINK("daily")}}) to go to the beta versions.

How you install these beta versions depends on your system.

### Linux/Raspberry

You can download the packages directly and then install them as described under [Package installation Raspberry](raspberry.md#packages) or [Package installation Linux](linux.md#packages).

If you are using an [AvNav image](raspberry.md#images), you can also set up the repository for the beta versions there. TODO

## Android

For Android, you can download and install the APK file directly. The application is then called "AvNav-beta" and can be used alongside a normal AvNav installation.

## Windows

On Windows, you can use the update function of the [installer](windows.md). You then enter the URL of one of the zip files from the list of betas under "Update".

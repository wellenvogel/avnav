# Agents hints

## PRs

Follow the [PR hints](PRHints.md).

## Android and Python

There are 2 server implementations - one at android and the other at server. Any changes that influence the API between the browser part (viewer) and the server need to be handled in both of them.

## Viewer
For any new file typescript must be used. Other files will be migrated to typescript step by step.

## Python
Currently the code needs to be compatible to Python down to 3.9.

## Environments
The python code needs to run on linux (x86, arm) and on Windows.
